# 手作课程工作室履约系统

工作室按学员报名与课程版本准备材料包，并跟踪「材料包去程 → 作品回寄 →
烧制/装裱加工 → 成品返寄」的完整履约链路。纯 Python 标准库实现，SQLite
持久化，照片本地存储，物流为模拟适配器。

## 一条命令启动

```bash
./run.sh            # 重建演示数据（含缺件案例）并启动 http://127.0.0.1:8000
./run.sh 8123       # 指定端口
./run.sh --no-reset # 保留现有数据启动
```

演示账号均为界面内操作（输入姓名模拟打包员/复核员/学员），无需登录。

## 关键业务规则

1. **版本锁定**：材料包按报名唯一生成（`enrollment_id UNIQUE`），清单在
   生成时从课程版本 BOM 快照到 `kit_lines`；之后课程改版不影响已生成的包。
2. **双人装箱**：打包员(packer)与复核员(checker)各确认一次，
   `UNIQUE(kit_no, role)` 防重复、`UNIQUE(kit_no, packer)` 防同人。
3. **双运单链路**：材料包去程 `CK-`、作品回寄 `HS-`、成品返寄 `FC-`，
   三张单号互不相同；成品按学员最新地址返寄。
4. **全量留痕**：缺件、未确认替代色、配送破损、迟交、地址变更、索赔、
   照片、每个状态动作均写 `exceptions` / `claims` / `address_changes` /
   `audit_log`。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：版本锁定、报名唯一建包、重复打包/同人双角色、缺件阻止封箱、
替代色确认、三运单链路、迟交留痕、地址变更按最新地址返寄、损坏索赔全流程、
无破损运单不可索赔、照片本地存储（12 个用例）。
